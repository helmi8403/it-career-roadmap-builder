Choice A Choice B Key discriminator

Application Gateway Front Door Regional L7 vs global edge L7/acceleration
Front Door Traffic Manager Proxy/L7 routing vs DNS-based traffic steering
VPN Gateway ExpressRoute Encrypted public internet tunnel vs dedicated private carrier path
Private Endpoint Service Endpoint Private IP for specific service vs service-restricted public endpoint routing
Azure Policy Azure RBAC Resource compliance vs actor authorization
Access Reviews PIM Attestation of membership vs just-in-time privileged activation
Azure Functions Container Apps Functions triggers vs container-first managed runtime/scaling
AKS Container Apps Kubernetes control vs reduced operational burden
Service Bus Event Grid Durable command/work queue vs push notification of events
Event Hubs Service Bus High-throughput streaming vs enterprise messages/sessions
SQL Database SQL Managed Instance Single database-first PaaS vs greater instance feature parity
Managed Instance SQL VM Managed PaaS compromise vs full OS and SQL control

ZRS GRS / GZRS Zone-level durability vs secondary-region copies
Blob versioning Immutable retention Past revisions vs enforced no-change/no-delete retention
Activity Log Resource diagnostic logs Control-plane subscription events vs data-plane/resource events
App Configuration Key Vault Feature flags/config vs secrets/keys/certificates
Data Factory Databricks Orchestration and data movement vs Spark-based analytics engineering
